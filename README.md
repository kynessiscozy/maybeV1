# 未发生事务所 · The Maybe Institute

为尚未发生的你，留一间工作室。

把一句「如果我想……」展开成三条可能性路线，再借给自己七天。本地优先，不替你做决定，不预测未来。

## 它是什么

一个本地优先的可能性工作台。首页只负责开门；自由实验、路线详情、恐惧模型、档案柜、记忆与设置，各自有房间。

- **展开**：念头变成三条路——微小的叛逃、认真的冒险、另一种人生。
- **落地**：其中一条写成七天小步骤，规模匹配你每天能借出的时间。
- **记住**：反馈会改默认推荐与任务体量。规则写死，日志可查，可以回滚。
- **回响**：每一次有后果的操作都留下一条看得见的记录，不是活动流水。

它不是算命软件，不是人生教练，也不是心理诊疗。

## 每一步都有回响

这个应用主张「允许生活出现计划之外的分支」，所以它不该只在三个地方给反馈。回响层（`src/features/echo.js`）把另外八类操作也接上：打卡、走完七天、收藏、展开念头、选预设、改资料、蒸馏、清空。

几个刻意的选择：

- **回响不等于活动日志。** 只有真正改变了什么的事才留痕。开关折叠块、切页、滑滑块都不算。
- **两套视觉语言分家。** 引擎回执（`⟳` / `REV`）说明「规则改了什么」；回响说明「刚刚发生了什么」。走完七天与引擎无关，硬塞进回执就得伪造一个状态增量。
- **取消是静默的。** 取消打卡只给 toast。给取消和完成一样的叙事重量，等于在用户想收回一步时施加压力。
- **全清不留痕。** 唯一一处沉默。在「我删掉了一切」上面记一笔，是这台机器不肯松手。
- **相位是派生的。** `src/features/journey.js` 的 `empty → seeded → started → midway → completed → archived → returned` 不写进存储——存下来的相位会在导入、回滚、清空之后与真实数据失同步。
- **刚刚发生的事优先于历史积累。** 相位的排序不是随手排的：`returned`（离开几天又回来）时间上最紧急，先认人；`completed`（刚走完七天）其次，最该被看见；`archived` 只描述「留下来过」，最容易变成过时的话，所以排在进度型相位之后。让一份旧档案盖住刚完成的七天，用户会在最该被看见的时刻读到一句过时的话。

页面据此改口径：档案柜空着时，对刚来的人说「还空着，未来不是」，对走到一半的人说「你还在路上，所以这里还空着」。后者才是实话。

### 压力画像与它接入的地方

`#/stress` 是一份 90 题（含效度与高危题）的 SPS 压力筛查测评，产出综合压力指数 CPSI（0–100）、五级预警、12 维度雷达与 4 主类型 × 4 反应通道。它不诊断、不评判，作答只留在本浏览器，支持中断续答（草稿存 `stress.draft`）。

画像结果会以三种方式回到应用：

- **恐惧模型读底色**：侧栏「压力底色」面板显示 CPSI 与安全桥接句；AI 上下文随之携带负荷约束——高负荷时不把话说重。
- **自由实验读底色**：橙/红区时默认胆量下调一档，轻提示说明原因，可拖回；一次会话只调一次，展开新念头后重置。
- **档案记忆存轨迹**：「学到的你」里有最近 12 次的负荷折线。自进化也有第三条规则：最近几次对话多数成功反驳了恐惧模型 → 任务规模再上调 10%。

### 自由实验的预设是怎么推荐的

`#/lab` 不是直接问「你想做什么」，而是先问「你现在更像哪一种处境」。选了处境之后，再选这一处境下说得通的动机；动机自带推荐的胆量与时间。最后一步「借一个念头」才会给出具体念头。

这个顺序的理由：对不知道自己想做什么的人，「独立杂志 / 周日咖啡角 / 造一个工具」这种标签和他是无关的；但从处境开始，他至少能认出「上班很满，下班没劲」或「有件小事一直想学」。

输入框里的字会改变第三级推荐：

- 你一开始没打字时，芯片是跨主题的通用样本（独立杂志、周日咖啡角、造一个工具……）。
- 一旦输入框里的文字命中某个主题的关键词（比如「重新学画画」命中 `learning` 主题），芯片会立刻换成该主题下的念头，标题也会变成「顺着你写的，找了几条」。
- 匹配用的是 `generate.js` 里同一份关键词表，所以「推荐出来的念头」和「展开后生成的行动模板」不会互相打架。
- 如果输入内容没命中任何主题，芯片不会假装听懂，而是继续按原来的处境 / 动机 / 通用样本走。
- 「换一批」也在同一个候选池里往后挪，不会从输入推荐跳回通用样本。

## 两个引擎

默认使用本地关键词匹配与策划好的行动模板，完全离线。

若在设置中填写兼容 OpenAI Chat Completions 的接口、模型名与 API Key，展开与恐惧模型对话时会把相关文本发往你指定的地址。失败自动回退本地结果。密钥以明文存在当前浏览器，请勿在公用电脑上保存。

模型生成的方案会连同 `engine: 'ai'` 标记一起存进本地（当前会话与收藏的档案各存一份），刷新、重开、从档案柜再次打开时仍是当初那份，不会退回本地模板重新生成。接口地址请使用 https——设置页会对明文 http 地址给出警告（localhost 等本机地址除外）。导出的 JSON 备份不含密钥，导入后需要重新填写。

## 本地运行

产物零外部依赖，可直接打开：

```bash
node build.js
```

生成 `outputs/index.html`。用浏览器打开即可，或：

```bash
node tools/server.js
```

### 验证

```bash
bash tools/guards.sh          # 静态守卫：ES5 写法、回响顺序、离线产物
bash tools/verify.sh          # 135 条端到端断言（浏览器只启动一次）
python3 tools/smoke_interaction.py   # 54 条交互冒烟：预设、折叠、生成
python3 tools/regression.py   # 77 组路由 × 视口的溢出与空视图检查
node tools/mobile-audit.js    # 移动端门槛：8 个页面的触控尺寸、字号、溢出
node tools/ios-audit.js       # iOS 四个视口的导航位置、触控、安全区快照
```

`tools/verify.sh` 会把每条断言写进一个共享脚本，由 `tools/abcli.js` 在同一个浏览器会话里顺序执行，最后统一比对。四个坑值得记下来：

- `page.evaluate` 里给 `location.hash` 赋值**不会**派发 `hashchange`（Chromium 只在真实导航时派发），`abcli` 检测到这种写法会补一次派发，否则路由停在原地。
- 断言结果分两类账：`#VAL` 对应浏览器 `eval`，`#ERR` 对应 `ab errors`。它们必须分开消费——如果让 `errors` 也占一个 `#VAL` 名额，它之后每条断言都会与结果错位一格，看起来像应用坏了。
- 本地模拟模型服务用 `/__version` 暴露版本戳。只判断「端口通不通」的话，改完 mock 旧进程还占着端口，新加的回退分支永远测不到。
- **脚本里的段落顺序是有语义的。** 视口切换（`setviewport`）对已经打开的页面只改量具，量到的数字取决于上一次 `open` 时的视口。所以「桌面端」的断言组不能夹在两组手机端断言中间——它会悄悄把后面的手机断言变成在 1440px 下跑。新增段落时先看清它落在哪个视口区间里。

写断言还有个教训：**「A 减 B < 2」这种式子，先想清楚它取等号的条件。** 预设选择器那段原本写成「容器宽 − 单卡宽 < 2」，本意是「一张卡占满整行」，但手机端本来就是两列（316 / 155），这个式子恒为 false。它从未绿过，却被误判成「视口没切过去」查了半天。正确的问法是「选择器容器的宽 == 它父级的宽」（证明没被当成普通网格项挤成半行），再加一条「列数 == 2」。

`tools/mobile-audit.js` 在 390×844 下逐页量测并截图到 `/tmp/mi-mobile`，任何一页出现触控目标不足、字号过小或横向溢出就以非零码退出。

## 插图

全站只保留**三张功能性插图**，其余页头与首屏的装饰图已全部移除。

| 保留 | 位置 | 为什么留 |
| --- | --- | --- |
| `archive` | 档案柜空态 | 空态是唯一没有内容可看的页面，图在这里承担「这里本该有东西」的说明作用 |
| `missing` | 404 / 路线无起点 | 同上：出错或空态时需要一张图解释「不是坏了，是还没有」 |
| `help` | 使用说明弹层 | 弹层本身遮住正文，图帮助定位「这是一段独立的说明」 |

删除的 9 张（landing / about / fear / memory / lab / route / settings / doors / days）都是**页头装饰**：它们在正文之上又占掉一屏的三分之一，信息量为零，只是把内容往下推。`src/core/art.js` 因此从 918 KB 降到 125 KB，构建产物从 1318 KB 降到 525 KB（**−60%**）。

这不是单纯的减法，省出的空间做了两件事：

- **正文上提。** `.page` 上下内边距 40 → 30px，`.page-head` 下边距 26 → 20px，页头与副标题之间再收 2px。没有插图之后，标题就是页面的第一视觉落点。
- **页面重排。** 首页原来靠四张插图撑起「四个去处」，现在换成带序号的纯文字卡（`.gallery-card`）——序号、标题、一句说明、一个箭头，四列网格。信息密度更高，也不再依赖图片体积。

## 移动端

手机是手持阅读距离，桌面那套「9px 当脚注尺寸」的排版不能直接搬过去。`src/styles.css` 末尾有一段独立的移动端基线，处理三件事：

| 问题 | 处理 |
| --- | --- |
| 正文大量 9px | 统一抬到 11–13px，正文类到 13–14px，行高略收 |
| 触控目标 31–34px | 全部抬到 44px 起：导航、分段控件、时间档位、平移方向键、文字链接 |
| 首屏内容被推低 | 插图全部移除后，标题与主按钮直接落在首屏 |

几个刻意的选择：

- **设置剥到右上角。** 设置和其它四项不是一类东西：那四项是「用这个工具做事」的去处，设置是「调整这个工具本身」。混在一排里，每次切页都要先跳过一个不同性质的项。现在它是页头右上角的齿轮图标（`#settings-button`），与日志按钮并排，进入 `/settings` 或 `/about` 时同 Tab 一样点亮。
- **顶栏收窄并钉住。** 页头从 100px 收到 90px（≤1150px 再收一档到 80px），并改为 `position: sticky` 常驻顶部——长页滚到一半也能直接跳转或开日志抽屉。用 sticky 而非 fixed，是为了不阻断 `.nav` 的 fixed 定位参照（fixed 子元素不受 sticky 祖先影响）；顶栏垫了不透明的纸色，正文从它下面穿过。
- **底部 Tab 栏。** ≤720px 时主导航从页头搬到屏幕底部并固定。理由是单手操作时拇指的活动区在屏幕下半部，页头左上角那排按钮要换手才点得到。移动端现在是**四项**（自由实验 / 恐惧模型 / 压力画像 / 档案记忆）。
- **Tab 栏是悬浮胶囊，不是通栏贴底。** 小屏下 `.nav` 左右各让 `12px + 2.5vw`——比通栏总宽收窄 5%（390px 屏约 22px/侧，另加安全区）、离底同样 12px；圆角写 `999px` 取极限值，只要 ≥ 高度一半两端就是标准半圆，激活格的内底色也做成整圆角，外胶囊套内胶囊、端部不打架。横屏收成 54px 高、8px 边距，胶囊同款。占位盒 `body::after` 用 `--tabbar-h + --dock-gap` 两个变量算高度，页尾内容永远不会被 Dock 盖住。
- **日志入口在页头，回响改为悬浮通知。** 事务所日志的常驻入口是右上角的图标按钮（`#ledger-open`）+ 条数角标；底部不再有常驻回响条——有新回响时，一条通知气泡在 Tab 栏（手机）/ 页脚（桌面）上方浮现几秒后自己收起（`#ledger-toast`），点它可以直达日志抽屉。正文末尾只需 `body::after` 为 Tab 栏让位。
- **高度常量收进变量。** `--tabbar-h` 一处定义，`.nav`、占位盒、`.ledger-toast`、`.toast` 全部引用。软键盘弹起时 `html.kb-open` 把变量归零，依赖同时失效。
- **滑块看得见的细，摸得到的宽。** 轨道仍是 4px，元素撑到 44px 并让轨道居中。
- **时间档位设 `min-width`。** 「15 / 45 / 90 分钟」三格是 `flex: 1` 等分，在 375px 屏上算下来每格只有 43.2px——差一点点不达标。补 `min-width: 44px` 兜住，屏幕再窄也不会掉下去。
- **小屏不降标准。** 385px 断点原本把导航压到 9px/7px 内边距，现在反而不再缩小——屏幕越窄越需要点得中。
- **两条豁免。** `.brand-en` 的 9px 英文标是有意的风格下限（≤720px 时直接隐藏），审计里显式放行。

## iOS

iOS 上有一套独立于 `/src/styles.css` 移动端基线的补充规则，按**指针类型**（`hover: none and pointer: coarse`）而非屏幕宽度触发，所以窄窗口的桌面浏览器不会被误伤。

针对「好奇心练习」这类主题在手机上暴露出的问题，还做了两处定向优化：

- **地图默认居中当前路线。** 可能性地图是一张 760–1420px 宽的虚拟画布，手机可视框只有 340px 左右，默认只能看到最左边一片空白。生成路线后 `centerRoute()` 会把当前选中的那列节点移到视野中央，用户一进来就看得见「认真的冒险」那条路，左右拖动再切到另外两条。
- **toast 改到顶部。** 手机底部被 Tab 栏占据，toast 放中间又会盖住地图。触屏媒体查询下把 toast 放到 `top: 12px`，既不被底部条挡住，也不遮主要内容。
- **七天任务项扩大触控区。** 手机上一行任务的标题、勾选框、难度按钮都抬到 44px 以上，字体也相应放大，避免手指点空。

| 问题 | 处理 |
| --- | --- |
| 横屏手机（844×390）落进桌面档，拿到 10px 字号与 26px 按钮 | 按「矮视口」（`orientation: landscape and max-height: 500px`）补一层，触控目标统一垫到 44px |
| 软键盘顶起时底部两条被压在键盘下 | `src/core/viewport.js` 监听 `visualViewport` 变化，加 `html.kb-open` 归零两个高度变量 |
| `env(safe-area-inset-*)` 恒为 0 | `shell.html` 的 viewport meta 补 `viewport-fit=cover`（这是安全区生效的唯一前置） |
| 输入框聚焦时整页被放大 | 触摸设备下输入控件字号统一 ≥16px（阈值是 16，不是 15） |
| 地图画布纵向划过变成滚动页面 | `.field-frame { touch-action: none }` |
| `:hover` 在点完后粘住 | 触摸设备下取消卡片位移，改为按下时的 `:active` 反馈 |

`node tools/ios-audit.js` 在四个视口（390×844 / 844×390 / 375×667 / 667×375）上记录导航位置、小触控数量、聊天面板高度与安全区数值。它**只记录不判定**，目的是让改动前后的数字可比。真机上的安全区与键盘数值仍需在设备上复核——沙箱里的 Chromium 这两项恒为 0。

## 数据

念头、档案、记忆、反馈与密钥默认只保存在本机 `localStorage`。无痕模式或清理站点数据会导致丢失，请在记忆页导出 JSON 备份。

回响账本同样存在本地，最多保留 40 条，最早的会被挤掉。它和其余数据一起导出、一起清空。导出的备份自动剥掉模型密钥，可以放心携带。
