A USER MANUAL FOR THE NOT-YET

欢迎来到，还没发生的地方。

这里不是算命软件，也不替你做决定。它是一个小小的可能性工作台，让模糊的念头有一张可以落脚的纸。

01
种下一个具体的念头在「自由实验」写下你想尝试什么，调整胆量和时间，再展开。Ctrl / ⌘ + Enter 也可以。
02
三条路，没有哪条更正确地图可以拖动，也可以用方向键在九个节点间移动、回车读建议。按 1 / 2 / 3 直接切换路线。
03
给它反馈，它会记住觉得某条路「不太像我」，或某个任务「太难」，都会立刻改变它下次给你的建议。每次调整都会当场给你一张回执，说明改了什么；这些记录在「档案记忆」的账本里可查、可回滚。
04
想要更贴身的建议，可以接入模型在「设置」里填入兼容接口的 API key。留空时一切由本地规则完成，同样可用。
诚实说明 默认引擎是本地关键词匹配加策划好的行动模板，不是大模型，不预测未来，不提供成功概率或收入估计。内容仅供灵感参考，不构成专业建议。

你的念头、反馈与学到的一切只保存在本浏览器，不会自动上传。只有当你主动在「设置」中启用模型接口后，相关文本才会发送到你指定的第三方服务。
